## 0. ドキュメント・方針

- [ ] リリース対象の定義（Web のみ / PWA / iOS アプリ / Android）

## 1. アカウント・認証

### 1.1 本番前に必須に近いもの

- [ ] **独自 SMTP** を本番 Supabase に設定（標準メールのまま一般公開しない）
- [ ] **Authentication → Providers → Email** で **Confirm email** が OFF（パスワード連携に必須。[SUPABASE_SETUP §3.1](./SUPABASE_SETUP.md#31-アカウント連携用の-authメールパスワード)）
- [ ] ホーム画面 PWA で **メール＋パスワード連携／ログイン**が通ること
- [ ] Safari / Chrome / ホーム画面アプリそれぞれで連携・ログイン・同期を確認
- [ ] 「アカウントを削除」の二段階確認・パスワード・端末初期化の動作確認
- [ ] `delete-account` Edge Function が本番 Supabase にデプロイ済みであること
- [ ] 空のクラウドアカウントでログインしても端末データが消えないこと
- [ ] レート制限時の日本語メッセージ確認
- [ ] 登録済みメールで「この端末を連携」するとログイン送信へ切り替わること

### 1.2 リリース近くで実装するもの（仕様は SUPABASE_SETUP「将来実装」）

- [ ] **Sign in with Apple**（iOS / 外部ログインを出す場合）
- [ ] **Google ログイン**（出す場合）

## 2. データ・同期

- [ ] 連携後の自動同期（保存 → 約3秒後アップロード）
- [ ] 設定の「クラウドに保存」「クラウドから復元」の動作
- [ ] 別端末ログインで復元できること
- [ ] `player_saves` のサイズ・無料枠の見積もり（想定ユーザー数）
- [ ] 本番 Supabase のバックアップ方針
- [ ] マイグレーション（`001`〜`004` 公開デッキ・セーブ、`005`〜`015` フレンド対戦）が本番に適用済みであること
- [ ] RLS（`player_saves` / `public_ghost_decks` / `online_battle_rooms`）で他人のデータが読めないこと

## 3. オフライン対人・経済

- [ ] 公開デッキの公開／非公開・一覧・対戦
- [ ] 戦力補正（出撃デッキ戦力）の体感確認
- [ ] 挑戦者のみ経済（戦利品・Lost）、作者デッキ不変
- [ ] CPU戦 / 対人オフラインの戦績が分かれて記録されること
- [ ] 広告モックを本番広告に差し替える計画（Web / アプリ）

## 3b. フレンド対戦（オンライン）

- [ ] migration **015**（`REPLICA IDENTITY FULL`）適用済み
- [ ] 2端末でルーム作成〜バトル〜clash 再生〜勝敗〜px 移動〜再戦／退出（[online-pvp-spec §8](./online-pvp-spec.md#8-受け入れ条件)）
- [ ] Lost が発生しないこと（フレンドルーム）
- [ ] 退出・再戦希望の相手向けメッセージ確認

## 4. PWA・モバイル

- [ ] ホーム画面追加の手順をヘルプやサイトに記載
- [ ] iOS で入力フォーカス時に画面が拡大しないこと（入力欄 16px）
- [ ] オフライン時の挙動（SW キャッシュ範囲・エラー表示）
- [ ] 本番 HTTPS・正しい `base` パス（例: `/Pixel_Battle/`）

## 5. セキュリティ・ビルド

- [ ] `.env` / Secrets に **service_role を入れていない**こと
- [ ] Auth の Site URL / Redirect URLs が本番・開発で正しいこと
- [ ] GitHub Actions の本番ビルドに `VITE_SUPABASE_*` が渡ること
- [ ] Pages デプロイが安定して成功すること
- [ ] 開発メニュー（DEV）が本番ビルドに出ないこと
- [ ] テスト指標（課金累計・広告視聴回数）の本番扱い（削除 or 非表示）
